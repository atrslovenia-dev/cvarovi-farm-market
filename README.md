# Cvarovi Farm Market

napiši mi zelo atraktivno strna za prodajo kmetijskih pridelkov in blaga na kmetiji pri cvarovih. Ponudba mora obsegati pos kupinah blaga torej recimo kmetijski pridelki(cela paleta) meso in živilski izdelki, les, gnojila,sadike, semena orodja, kmetijski stroji, kmetiski objekti in kmetiks oprema vse z vzorčimin slikami slovenske kmetije. shopping cart mora temljiti izključno na html dodajanje in managiranje assetov pa mora potekati preko posebne nadzorne plošče na katero se mora uporabnik prijaviti z uporabniškim imenom ki je harcodan oz v kodi login forme uporabi torej samo najnovješi standard html in nič drugega
